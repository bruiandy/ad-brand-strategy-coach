# 策略能力练习AI

品牌与广告传播策略陪练 Skill，帮助你理解好策略的结构、识别思考缺口，并逐步讨论依据、选择与取舍。

**中文名称：策略能力练习AI**  
**技术标识：`ad-brand-strategy-coach`**  
**当前版本：2.1.0**

## 它帮助你练习什么

方法很多，资源有限。策略要在目标、约束和现有信息下形成诊断、决定取舍，并选择有依据、可检验的行动路径。

本工具聚焦品牌与广告传播：为了帮助具体的商业目标，选定要影响的人和竞争背景，理解他们当前的认知或态度（A），明确期望的变化（B），再判断传播承担什么作用、集中传递什么、凭什么可信，以及如何符合品牌已有的资产与承诺。

AI提供解释、诊断、候选判断与比较。重要选择需要使用者参与，缺失证据会明确保留。

## 对话怎么推进

首轮依次完成：

1. 讲清策略的重要性与完整逻辑。
2. 解释九个判断节点如何共同服务这条逻辑。
3. 将你已经提供的信息映射到进度表。
4. 诊断当前最关键的缺口，推进一个判断。

后续每轮保持固定的九项进度，根据新增信息更新阶段，允许回退。资料少时，可以获得一份学习与缺口小结；资料充分时，进入候选策略、依据、取舍与验证前提的讨论。

| 阶段 | 判断节点 |
|---|---|
| 商业起点 | 0 真实生意来源 |
| 人群与竞争 | ① 目标对象、② 竞争范畴 |
| 认知变化 | ③ 传播角色、④ 当前认知Point A、⑤ 期望变化Point B |
| 主张与证据 | ⑥ 单一核心信息、⑦ 支持点 |
| 一致性与闭环 | ⑧ 品牌定义与闭环 |

九项是同一条逻辑中的判断节点。A/B指消费者的认知或态度变化，需要说明它如何帮助商业目标。

## 使用示例

将下面的内容交给支持 Skill 的 AI 工具：

```text
使用 $ad-brand-strategy-coach 陪我练习品牌与广告传播策略。
我们有一款零食，现有买家反馈不错，同类产品也很多。
我想做传播，但不确定应该先影响谁、改变什么看法。
请先解释完整策略逻辑和判断节点，再结合我已有的信息推进。
```

普通的脚本创作、投放优化、渠道定价和供应链管理不自动进入这套流程。价格、产品、渠道和资源可以作为策略判断的条件；明确转做执行时，需保留尚未解决的策略前提。

## 验证状态

2.1.0已完成文件结构、相对引用、首轮流程规则与压缩包完整性检查。对话试跑曾暴露进度不清晰、过早进入内容拍法、框架解释衔接不足等问题，本版已据此修改并加入回归检查条件。

## 版本变化

- **2.1.0：** 首轮采用“完整策略逻辑→九个判断节点→本案信息映射”；明确A/B与商业目标的关系，区分增长意图和证据，检查销售排名能支持的主张范围。
- **2.0.0：** 增加策略重要性、固定九项进度、动态阶段、轻量学习与深入讨论交付，强化策略与内容执行的边界。
